## Fișiere
- index.html
- style.css

## Unde modifici linkurile
Deschide `script.js` și caută:

SITE_CONFIG.discord

și, în fiecare modpack:

download: "..."

Înlocuiește valorile cu linkurile reale.

## Unde pui pozele
Creează:
assets/images/modpacks/

și pune pentru fiecare modpack:
mp1-cover.jpg
mp1-1.jpg
mp1-2.jpg
mp1-3.jpg

mp2-cover.jpg
mp2-1.jpg
mp2-2.jpg
mp2-3.jpg

mp3-cover.jpg
mp3-1.jpg
mp3-2.jpg
mp3-3.jpg

mp4-cover.jpg
mp4-1.jpg
mp4-2.jpg
mp4-3.jpg

`cover` este poza de pe card, iar celelalte sunt imaginile din popup.

Site-ul are momentan imagini placeholder generate din SVG/CSS dacă nu ai încă pozele; pentru versiunea finală este recomandat să le înlocuiești cu capturile tale.
